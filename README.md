# Bright TV Viewership Analytics

## Project Overview

This project analyses Bright TV user profiles and viewership data to identify viewing trends, audience behaviour, channel performance, and factors influencing content consumption. The analysis was completed using SQL, Databricks, Excel, and various data visualisation tools to provide business insights and recommendations for growing Bright TV's subscription base.

## Project Objectives

* Analyse user and viewership trends
* Identify factors influencing content consumption
* Analyse channel performance and peak viewing periods
* Understand audience behaviour and demographics
* Recommend strategies to increase viewership and subscriptions
* Present findings through interactive dashboards and a presentation

## Project Workflow

1. Review the project requirements.
2. Plan the project architecture and timeline.
3. Import and clean the dataset.
4. Process and transform the data using Databricks SQL.
5. Analyse viewership patterns and audience behaviour.
6. Develop interactive dashboards.
7. Present insights and business recommendations.

## Key Insights

* Overall viewership trends
* Channel performance analysis
* Peak viewing hours and days
* Audience demographics and segmentation
* Viewer behaviour and content consumption patterns
* Factors influencing customer engagement

## Business Recommendations

* Promote popular content during low-viewership periods.
* Recommend personalised content based on viewing behaviour.
* Invest in high-performing channels and content categories.
* Launch targeted marketing campaigns to attract new subscribers.
* Introduce customer loyalty and referral programmes.
* Monitor viewing trends through automated dashboards for continuous improvement.
